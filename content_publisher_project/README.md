# ناشر المحتوى الذكي (Content Publisher App)

تطبيق أندرويد متكامل لإدارة ونشر الفيديوهات على:
* **تيك توك (TikTok)**
* **يوتيوب (YouTube)**
* **فيسبوك (Facebook)**

---

## 🚀 كيفية استخراج ملف الـ APK وتثبيته على هاتفك مجاناً في دقيقتين:

### الطريقة الأولى: عبر GitHub Actions (أسهل طريقة بدون تثبيت أي برامج على جهازك)
1. افتح موقع [GitHub.com](https://github.com) وقم بتسجيل الدخول.
2. اضغط على **New Repository** وأنشئ مستودعاً جديداً (Private أو Public).
3. فك الضغط عن هذا المجلد وقم برفع جميع الملفات داخله إلى المستودع.
4. بمجرد رفع الملفات، توجه إلى تبويب **Actions** في صفحة المستودع على جيت هاب.
5. ستجد مهمة البناء `Build Android APK` بدأت تلقائياً.
6. بعد حوالي 3 دقائق، ستجد ملف الـ `app-release.apk` جاهزاً للتحميل المباشر تحت قائمة **Artifacts**!
7. حمله على هاتفك واضغط "تثبيت" (Install).

---

### الطريقة الثانية: عبر جهاز الكمبيوتر (Android Studio أو Flutter)
إذا كان لديك Flutter أو Android Studio:
```bash
# 1. تثبيت الحزم
flutter pub get

# 2. بناء ملف الـ APK
flutter build apk --release
```
ستجد الملف الناتج في المسار:
`build/app/outputs/flutter-apk/app-release.apk`

---

## ✨ أهم الميزات:
1. **رفع الفيديو محلياً** من ذاكرة الهاتف واختيار العنوان والهاشتاجات.
2. **أزرار مخصصة لكل منصة**:
   - يوتيوب: نسخ العنوان وفتح شاشة الرفع.
   - فيسبوك: نسخ النص تلقائياً لسهولة لصقه مع تجاوز قيود فيسبوك.
   - تيك توك: نسخ العنوان والهاشتاجات وفتح شاشة النشر.
3. **خانات اختيار (Checkboxes)** لمعرفة المنصات المنشورة وقياس نسبة الإنجاز (0% إلى 100%).
4. **زر مشاركة أندرويد المباشر (Share)** لتمرير ملف الفيديو فوراً لأي تطبيق مثبت بهاتفك.
